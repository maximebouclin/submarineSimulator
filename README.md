# OpenGL Submarine Simulator

A 3D submarine simulation written in C using OpenGL and GLUT.

## Overview

This project is a real-time 3D graphics simulation that renders a submarine navigating an underwater environment. The simulator was developed to explore low-level computer graphics programming concepts including transformations, lighting, textures, camera movement, and interactive rendering.

The application uses OpenGL and GLUT to render a dynamic 3D scene with keyboard and mouse controls for user interaction.

---

## Features

- Real-time 3D rendering using OpenGL
- Interactive camera movement and scene navigation
- Dynamic lighting and material effects
- Textured underwater environment
- Custom 3D submarine model rendering
- Keyboard and mouse controls
- Perspective projection and transformations
- Surface normals for lighting calculations

## Running the Project

### Requirements

- OpenGL
- GLUT / FreeGLUT
- GCC or another C compiler

### Build Example (Linux)

bash gcc submarineSimulator.c -o submarineSimulator -lGL -lGLU -lglut -lm 

### Run

bash ./submarineSimulator
